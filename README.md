
# 📊 SQL Practice Exercises

## 📌 Project Overview
This repository contains a collection of SQL practice exercises completed to strengthen my understanding of database querying, data analysis, and problem-solving using SQL.

The exercises cover foundational to intermediate SQL concepts commonly used in data analytics, reporting, and database management.

Through these exercises, I practiced writing efficient queries, filtering data, combining datasets, handling missing values, and generating meaningful insights from structured data.

---

## 🎯 Objectives
The goal of this project was to:

- Build a strong SQL foundation
- Improve query-writing skills
- Understand data retrieval and manipulation
- Practice solving real-world data problems
- Strengthen skills relevant to Data Analytics 

---

## 📚 Topics Covered

### 1️⃣ SQL Fundamentals
- SELECT statements
- Filtering data using `WHERE`
- Sorting results using `ORDER BY`
- Limiting outputs
- Understanding basic query structure

### 2️⃣ Aggregate Functions & SQL Operators
- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()` and `MAX()`
- `GROUP BY`
- `HAVING`
- SQL comparison operators
- Logical operators for filtering and analysis

### 3️⃣ CASE Statements
- Conditional logic in SQL
- Categorizing and labeling data
- Creating calculated fields using `CASE WHEN`

### 4️⃣ SQL Joins
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- Combining data from multiple tables
- Understanding relationships between datasets
- Understanding database limitations and SQL dialect differences

### 5️⃣ Date Functions
- Working with dates in SQL
- Extracting date components
- Date calculations
- Formatting and filtering date-based data

### 6️⃣ NULL Functions
- Handling missing values
- `COALESCE()`
- `IFNULL()` / `ISNULL()`
- Managing incomplete datasets

### 7️⃣ UNION & UNION ALL
- Combining query results
- Removing duplicates using `UNION`
- Keeping duplicates using `UNION ALL`
- Comparing datasets across multiple tables

## 🚀 Learning Outcome
Completing these exercises strengthened my ability to work with structured data using SQL and improved my understanding of how databases are queried and analyzed in real-world environments.

Beyond core SQL concepts, I also learned how different SQL dialects behave differently. While working with joins, I discovered that MySQL Workbench does not support `FULL OUTER JOIN` directly and practiced alternative solutions using `UNION` to achieve similar results.

This repository reflects my continuous learning journey in **Data Analytics**, while building practical skills relevant to real-world data analysis.
