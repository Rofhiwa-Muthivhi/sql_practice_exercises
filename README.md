## Exercises Completed

### 01_SQL Fundamentals

In this exercise I practiced basic SQL querying techniques used to retrieve and organize data from tables.

Topics covered:

* `SELECT` statements
* `DISTINCT`
* `ORDER BY`
* `LIMIT`
* `WHERE` clause
* Logical operators (`AND`, `OR`, `NOT`)

These queries focus on **filtering, sorting, and selecting specific data from tables**.

---

### 02_Aggregate Functions and SQL Operators

This exercise focused on summarizing and comparing data using SQL functions and operators.

Topics covered:

* Aggregate functions such as:

  * `COUNT()`
  * `SUM()`
  * `AVG()`
  * `MIN()`
  * `MAX()`

* SQL operators including:

  * Comparison operators (`=`, `>`, `<`, `>=`, `<=`)
  * Logical operators (`AND`, `OR`, `NOT`)

These functions help analyze data by **calculating totals, averages, and identifying patterns in datasets**.
